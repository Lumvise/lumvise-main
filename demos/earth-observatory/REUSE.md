illustrations lacked established reuse permission for this collection. It has been
replaced with the original CC0 PDF; it must not be added back merely because it is
publicly downloadable. The exclusion checksum is retained in `sources.json`.

examples uniform CC0 terms. This does not assert that NASA prohibits reuse;
its agency-specific conditions no longer apply to the replacement illustration.

This notice covers the current source folder. The running app retains inactive
historical index records for the removed handbook. They were not physically purged.

package; exclude retired source content before exporting. No such export is included.
